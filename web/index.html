采集管理

从网上收集内容，或导入手头的文件和文字。两种方式添加的内容都可以在素材库查看。

跟踪账号和话题

填写要读取的作者或话题。平台作品由本机 Chrome 或 Edge 中的「DM 发布助手」采集。

如何安装助手并开始采集？
  1. 在运行工作台的电脑上，用 HTTP 打开 localhost 或 127.0.0.1（默认端口 8765）。
  2. 下载 DM 发布助手并解压。在浏览器扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹，再刷新工作台。
  3. 添加任务并点「立即采集」。点「去登录并继续」打开平台，在该标签页核对或登录采集账号。如果登录后离开了目标页，返回工作台再点一次继续。
  4. 在目标页打开工具栏的「DM 发布助手」，点「采集此页作品并提交」，按提示允许访问当前平台。保持弹窗打开直到出现结果，再返回工作台查看批次。

采集后能得到什么？

图文会尝试读取正文、保存配图并识别图片文字。视频会尝试取得字幕或转写讲话，再抽取关键画面解析。素材库保留原始依据，并逐项说明未取得的内容。视频画面采用采样，不是逐帧读取。

本机数据保存

        
在工作台电脑运行 python backup.py location 可查看当前数据库的完整路径。

        
工作数据库保存全部项目、素材、配图、稿件和账号日报。当前使用本机 SQLite，工作台会自动创建和管理，不需要填写连接信息。

        
Notion／飞书资料库在「采集管理 → 按渠道采集 → 资料库」管理。导入的素材、稿件和历史记录保存在这里。

        
更换本机保存文件夹
仅在需要保存到另一块硬盘时修改。填写的是运行工作台的电脑上的路径，不是手机路径或数据库地址。

        
        
保存前会复制并校验全部项目。原位置保留；目标已有数据库时不会覆盖。外接硬盘需要在使用期间保持连接。

        

        

      

      
备份与恢复全部项目
        
在运行工作台的电脑上打开项目目录，用下面的命令导出 SQLite 备份。备份可能包含已保存的资料库凭据，请保存在受控位置。

        python backup.py export <新的备份文件>
        
核验备份的完整性与运行记录字段，再恢复到空目录试读稿件。服务密钥和模型配置文件需要单独保管。

        python backup.py verify <备份文件>
        
恢复时指定一个未存放工作数据库的目录。可在启动前将 DM_DATA_DIR 指向恢复目录，打开工作台查看这些项目。

        python backup.py restore <备份文件> --directory <目标数据目录>

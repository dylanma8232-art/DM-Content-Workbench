# DM 内容工作台全面强化计划

用户确认：保留「DM 内容工作台」，融入作者既有「栗子」橘猫 IP。全部关键能力应在 HTML 页面提供配置、保存、检测、执行和结果说明，不要求普通操作者编辑环境变量。

## 交付顺序与验收

- [x] 数据入口统一：本地导入、Notion／飞书等指定资料库、六个平台账号和话题。每条入口说明适用范围、所需授权、操作步骤和导入结果。
- [x] 存放配置可理解：默认本机保存；支持更换工作台电脑的存放目录，明确迁移范围与结果，默认不展示个人绝对路径。线上资料库和本机存放区别清楚。
- [x] 阶段配置中心：按采集、存放、清洗、分析、选题、成稿、审核发布组织设置；项目配置与全局连接范围清晰。每个阶段有直达设置入口、保存反馈和生效范围。
- [x] 清洗强化：长度、去重方式、相似阈值、排除词、链接处理；保留原素材、剔除原因；人工保留／剔除后可继续推进。
- [x] 分析强化：证据摘录数量、关注方向、规则／模型选择；生成跨素材研究结论与缺失提醒；模型引用必须能回查原始证据。
- [x] 选题强化：可配候选数量和来源门槛，显示排序理由和关联素材；允许人工确认正式标题。
- [x] 成稿强化：受众、形式、目标篇幅、写作要求、提纲配置；模型写作与证据整理区分；编辑、版本对比、审核意见和通过／退回有明确入口。
- [x] 审核与发布一致：关联稿件的发布内容绑定审核版本，修改后重新审核；人工确认最终发布；既有发布辅助继续可用。
- [x] 前端整体升级：统一颜色、字号、间距、按钮、表单、分区、列表、状态、错误和空状态；桌面导航与手机布局都能完整操作；栗子 IP 使用真实既有品牌素材。
- [x] 可核查交付：后端规则与配置测试、浏览器实际保存与执行测试、桌面与 320px 手机检查、打包检查；真实账号验证与模拟验证分开记录。

## 范围约定

- 采集平台固定为小红书、B站、抖音、Instagram、TikTok、X。
- Notion／飞书线上资料库首先是读取素材入口；不得因为已连接就宣称工作数据全部存到线上。
- 保留现有数据和原始依据；自动分析不冒充作者原话或已核实事实。
- 不自动发布、发消息、提交代码或推送仓库。
- 不重写他人已存在的未提交工作，不把本机配置、数据库、日志和个人路径打入分发包。

## 仍需实际账号验收的边界

- Notion／飞书读取及审核稿归档的自动测试使用模拟远端响应；尚未用真实授权验收远端读写。连接和归档都需有效权限，不能因测试通过宣称真实账户已接通。
- 六个平台均有入口和任务配置。此前 B站公开样本已做真实采集、语音与画面解析；其余平台仍需登录账号验收，平台登录、访问限制和页面变化会影响结果。
- AI 引用校验保证引用 ID 存在，不等同于事实核查或保证语义完全正确；选题和稿件仍需人工审核。
- 视频仅分析已获取字幕／语音及采样画面，不代表完整观看所有视频。线上资料库仍不替代本机工作主库。
- 未代为发布作品、写入真实线上资料库、提交或推送仓库。
